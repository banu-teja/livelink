## 2025-02-23 - Cross-Site WebSocket Hijacking (CSWSH) in Python Local Servers
**Vulnerability:** Local development servers using libraries like `websockets` without explicit Origin checks allow any website (including malicious ones) to connect to the WebSocket endpoint if the user visits the attacker's site while the local server is running.
**Learning:** `websockets` (and many similar libraries) do not enforce Origin checks by default. When building agents or dev servers that bind to `localhost` and run locally, browsers will happily send requests to `localhost` from any arbitrary web page. If the server doesn't check the `Origin` against the `Host`, an attacker can hijack the connection and potentially interact with the agent or execute commands.
**Prevention:** Always implement an `Origin` check in the WebSocket connection handler or `process_request` hook. The simplest valid check is comparing `urllib.parse.urlparse(origin).netloc` to the `Host` header when `cors` is disabled.
