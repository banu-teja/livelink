## 2026-10-25 - Cross-Site WebSocket Hijacking (CSWSH) in serve.py
**Vulnerability:** The `agent.serve()` method hooks into the HTTP handshake using `websockets` via the `process_request` callback. Without explicit validation of the `Origin` header, the custom implementation inadvertently accepted cross-origin WebSocket requests.
**Learning:** This architectural gap happened because standard HTTP mechanisms (like CORS) don't naturally protect WebSocket handshakes when implementing custom `process_request` callbacks. The assumption that normal WebSocket libraries would handle this automatically was bypassed by intercepting the handshake.
**Prevention:** Whenever intercepting or manually handling WebSocket handshakes (e.g., via `process_request`), explicitly validate the `Origin` header against the `X-Forwarded-Host` or `Host` header to ensure the request is not originating from a malicious cross-site origin. Return a `403 Forbidden` response to block illegitimate handshakes.
