## 2025-05-24 - [CRITICAL] Prevent Cross-Site WebSocket Hijacking (CSWSH)
**Vulnerability:** The custom WebSocket server implementation (`livelink.serve`) lacked validation of the `Origin` header during the HTTP upgrade process when `cors` was disabled. This could allow malicious websites to initiate WebSocket connections to the local server on a user's behalf (CSWSH), potentially hijacking voice agent sessions.
**Learning:** When directly using `websockets.asyncio.server.serve`, the library does not enforce origin checks by default. We must explicitly hook into `process_request` to validate the `Origin` against the `Host` or `X-Forwarded-Host` headers to prevent unauthorized cross-origin connections while handling edge cases like IPv6 formatting.
**Prevention:** Implement explicit `Origin` vs `Host` validation in the `process_request` hook, ensuring a fail-closed response (`http11.Response(403)`) for mismatched or unparseable origins. Apply this validation strictly when explicit cross-origin access (`cors=True`) is not enabled.
