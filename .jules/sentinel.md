## 2025-02-14 - [HIGH] Fix Cross-Site WebSocket Hijacking (CSWSH) vulnerability
**Vulnerability:** The custom WebSocket server implementation (`src/livelink/serve.py`) handled connections without verifying the `Origin` header against the expected `Host`. This allowed any external domain to hijack a user's session if they were logged in, leading to Cross-Site WebSocket Hijacking (CSWSH).
**Learning:** When creating a custom process for request handling in websockets (like `process_request`), standard protections like CORS or Origin checking aren't automatically applied unless explicitly implemented. This creates a surprising security gap where the application appears secure but lacks essential WebSocket security measures.
**Prevention:** Always validate the `Origin` header against the expected `Host` (or `X-Forwarded-Host`) during the WebSocket handshake when a server implementation does not do it by default. Specifically for `websockets`, this involves intercepting `process_request` and rejecting unauthorized origins.
