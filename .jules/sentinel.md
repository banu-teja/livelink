## 2024-10-21 - Fix Cross-Site WebSocket Hijacking (CSWSH) vulnerability
**Vulnerability:** The `src/livelink/serve.py` file didn't validate the `Origin` header during the WebSocket connection handshake in `process_request`. This allowed any website to connect to the WebSocket server running on `localhost` (or any other host) on behalf of a user and interact with the LiveLink agent, resulting in a Cross-Site WebSocket Hijacking (CSWSH) vulnerability.
**Learning:** `websockets` library does not automatically enforce `Origin` checks. When defining a custom `process_request` handler that accepts cross-origin requests by default (if returning `None` and continuing the handshake), explicit `Origin` validation against expected hosts (e.g., via the `Host` or `X-Forwarded-Host` header) is required to prevent CSWSH.
**Prevention:** Always implement `Origin` header validation against `Host` or `X-Forwarded-Host` when accepting WebSocket connections in a browser context. Return an HTTP 403 Forbidden response if the origin is untrusted.
