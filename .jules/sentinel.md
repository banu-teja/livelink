## 2024-10-12 - Prevent Cross-Site WebSocket Hijacking (CSWSH)
**Vulnerability:** The WebSocket server implemented with the `websockets` library and a custom HTTP handler (`process_request`) did not validate the `Origin` header against the `Host` header. This allowed any website to establish a WebSocket connection to the server on behalf of an authenticated user, leading to Cross-Site WebSocket Hijacking (CSWSH).
**Learning:** When taking over HTTP handshake handling using custom `process_request` functions in `websockets` or similar libraries, the default protections (such as CORS or CSWSH) are bypassed. Explicit validation of the `Origin` header is required to ensure the upgrade request originates from an allowed source.
**Prevention:** Always validate the `Origin` header against the expected `Host` or a list of allowed origins before accepting a WebSocket upgrade request, especially when `cors` is disabled or when overriding the default framework handshake handlers.
