## 2025-02-12 - Prevent Cross-Site WebSocket Hijacking (CSWSH) in built-in server
**Vulnerability:** The built-in WebSocket server (`livelink/serve.py`) using `websockets` library did not validate the `Origin` header against the `Host` header by default during the WebSocket handshake. This could allow malicious websites to establish WebSocket connections on behalf of the user if they were visiting the attacker's site while running a LiveLink server locally or in an accessible network, leading to Cross-Site WebSocket Hijacking (CSWSH).
**Learning:** The `websockets` library (unlike some HTTP frameworks) does not enforce CORS on the WebSocket upgrade request by default unless explicitly configured in `process_request`. Custom implementations handling connections and HTTP handshakes directly via `process_request` must explicitly validate the `Origin` header.
**Prevention:** Always validate the `Origin` header during the HTTP upgrade request for WebSockets, especially when dealing with custom session management or when `cors` is explicitly disabled, to ensure connections originate from expected sources.
